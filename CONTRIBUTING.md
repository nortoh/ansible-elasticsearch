## Opening a PR

Use this repo's [PR template](.github/PULL_REQUEST_TEMPLATE.md) — link the ticket or issue and describe how you verified the change.

## Before you open a PR

- [ ] `bundle exec kitchen test <PATTERN>` passes locally for any suite your change affects
- [ ] Docs (`README.md`/`AGENTS.md`) updated if this changes how the role is configured or run
